# Lyrico 插件

[Lyrico](https://github.com/Replica0110/Lyrico) 的搜索源插件集合，提供歌曲信息、歌词和封面。

## 订阅链接

```text
https://github.com/Replica0110/Lyrico-Plugins/releases/latest/download/catalog.json
```

进入插件管理页，点击右上角“＋” → **在线订阅**，粘贴链接，获取列表后选择插件安装。

更新时，在同一菜单点击**检查更新**，再点击插件条目上的更新按钮。

## 本地导入

从 [Releases](https://github.com/Replica0110/Lyrico-Plugins/releases/latest) 下载 ZIP，在插件管理页选择**本地导入**。

单插件包用于安装指定插件；`Lyrico-Plugins.zip` 可一次导入全部插件。

使用问题见 [使用说明](https://replica0110.github.io/Lyrico/plugins/using.html)，异常请通过 [Issues](https://github.com/Replica0110/Lyrico-Plugins/issues) 反馈。
