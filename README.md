# Lyrico 插件

[Lyrico](https://github.com/Replica0110/Lyrico) 的官方搜索源插件集合。

为 Lyrico 提供来自各大音乐平台的歌曲搜索、歌词获取和封面搜索能力。安装插件后，你可以在 Lyrico 中直接搜索和补全歌曲信息。

## 可用插件

| 插件 | 支持平台 | 说明 |
| --- | --- | --- |
| 网易云音乐 | 网易云音乐 | 支持搜索歌曲、获取歌词和封面 |
| QQ 音乐 | QQ 音乐 | 支持搜索歌曲、获取歌词和封面，可配置封面尺寸和回放增益 |
| 酷狗音乐 | 酷狗音乐 | 支持搜索歌曲、获取歌词和封面 |
| 汽水音乐 | 汽水音乐 | 支持搜索歌曲、获取歌词和封面 |
| Apple Music | Apple Music | 支持搜索歌曲、获取歌词和封面，可配置地区、语言、歌词源和封面尺寸 |

每个插件都支持搜索歌曲、获取歌词和搜索封面。部分插件提供额外配置选项，如封面尺寸、地区偏好等，可在 Lyrico 的插件管理页面中调整。

## 安装方式

前往 [Releases](https://github.com/Replica0110/Lyrico-Plugins/releases) 页面下载所需插件的 ZIP 包，然后在 Lyrico 中导入：

1. 打开 Lyrico，进入插件管理页面
2. 选择下载的插件 ZIP 文件
3. 确认安装

详细步骤和常见问题请参阅 [使用插件](https://replica0110.github.io/Lyrico/plugins/using.html) 文档。

## 发行版说明

每个 Release 中包含以下文件：

- **单插件包**（如 `com.neteasecloudmusic.source-0.2.1.zip`）：按需下载，只安装你需要的音乐平台。
- **聚合包**（`Lyrico-Plugins.zip`）：包含全部插件，一次性导入即可获得所有平台支持。
- **release-manifest.json**：机器可读的版本元数据。

## 问题反馈

安装或使用插件时遇到问题？请在 [Issues](https://github.com/Replica0110/Lyrico-Plugins/issues) 中反馈。

搜索不到歌曲、歌词缺失等问题通常与插件所连接的平台服务有关，建议附带以下信息以便排查：

- 使用的插件及版本
- 搜索的关键词
- Lyrico 应用版本
